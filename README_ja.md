# BeFake
フロントカメラとバックカメラで同時に写真を撮影し、1枚の合成画像にカスタマイズ可能な透かし（ウォーターマーク）を添えて結合する、スタンドアロンのAndroidカメラアプリです。BeRealのカメラ機能にインスパイアされています。

[English](README.md) | 日本語

## 概要
撮影ボタンを押すと、フロントカメラとリアカメラが同時に写真を撮影します。生成される画像は両方を組み合わせたもので、フロントカメラの写真がメイン画像として画面全体を占め、バックカメラの写真はBeRealの特徴的なデュアルカメラレイアウトと同様に、左上に小さな角丸のオーバーレイとして表示されます。撮影後は、保存前にメイン画像とインセット画像のカメラを入れ替えることができます。

## BeRealとの違い
BeFakeは、BeRealではない要素をすべて取り除いています——ソーシャルネットワークなし、通知なし、トレンド時間なし、フレンドフィードなし。純粋にカメラ機能のみを、出力を完全にコントロールできるスタンドアロンアプリとしてゼロから再構築しています。

- **カスタマイズ可能な透かしテキスト** — 合成画像の下部に表示する任意のテキストを設定できます（デフォルト: "BeFake."）
- **透かしの色** — 任意の色を名前で指定できます（例: `black`、`white`、`#FF5733`）
- **透かしの不透明度** — アルファ値を0から100の範囲で調整できます
- **透かしのフォントサイズ** — テキストサイズを好みに設定できます
- **枠線の色と不透明度** — バックカメラのインセット写真の周りの枠線をカスタマイズできます
- **撮影品質モード** — 画質の最大化と撮影レイテンシの最小化のどちらかを選択できます
- **レイアウトの反転** — 撮影後にメイン画像とインセット画像のカメラを入れ替えられます
- **透かしのオン/オフ切り替え** — 保存前のプレビューで透かしの表示/非表示を切り替えられます

## 技術スタック
- **言語:** Kotlin
- **最小Androidバージョン:** 11 (API 30)
- **ターゲットAndroidバージョン:** 13 (API 33)
- **コンパイルSDK:** 34
- **カメラ:** [CameraX](https://developer.android.com/training/camerax)（`ConcurrentCamera`によるデュアルレンズ同時撮影）
- **画像合成:** 合成処理と透かし描画にAndroidの`Canvas`および`Bitmap` APIを使用
- **永続化:** 設定の保存にAndroidの`SharedPreferences`を使用
- **EXIF処理:** 画像の正しい回転のために`ExifInterface`を使用
- **ビルドシステム:** Gradle (Kotlin DSL)

## ビルド方法
前提条件: Android SDK 34がインストールされた[Android Studio](https://developer.android.com/studio)

1. Android Studioでプロジェクトを開きます（`File > Open`を選択し、このディレクトリを指定）。
2. プロンプトが表示されたらGradleファイルを同期します。
3. **開発者向けオプション**と**USBデバッグ**を有効にしたAndroid端末をUSBで接続します。
4. Android Studioの実行ボタン（▶）をクリックしてビルド・デプロイします。

Playストアでの配信はありません——インストールはソースからのADB/デプロイのみです。

## プロジェクト構成
```
app/src/main/java/com/georgeneokq/befake/
  MainActivity.kt          — デュアルカメラプレビュー、撮影ロジック、タップフォーカス、ドラッグ可能なインセット
  CapturePreviewActivity.kt — 合成画像のレンダリング、透かし描画、保存/反転コントロール
  SettingsActivity.kt      — 透かしと枠線のカスタマイズUI
  Globals.kt               — アプリ全体の定数
  util/Util.kt             — バイブレーション、角丸キャンバスのビットマップユーティリティ、設定リセット
  components/FlashOverlay.kt — 撮影時の白いフラッシュアニメーション
```
